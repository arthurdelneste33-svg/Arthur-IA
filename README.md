# Arthur IA — Plateforme d'Assistance & Modèles Multimodaux

**Arthur IA** est une application web moderne et responsive conçue pour centraliser et orchestrer des capacités d'intelligence artificielle avancées. Proposant une interface unifiée, l'application intègre le traitement du langage naturel, la génération multimédia, l'analyse documentaire et la synthèse vocale.

---

## 🚀 Fonctionnalités principales

* **Chat & Raisonnement Adaptatif :** Interface de conversation fluide proposant 3 niveaux de puissance de traitement :
  * **Mode Rapide :** Traitement à faible latence pour les requêtes courantes.
  * **Mode Normal :** Équilibre optimal entre rapidité et profondeur d'analyse.
  * **Mode Réflexion Avancée :** Analyse complexe avec affichage de la chaîne de raisonnement.
* **Génération Audio & Musique :** Module de création sonore par description textuelle (prompts), sélection de genres et exportation des pistes audio.
* **Génération d'Images HD :** Création d'illustrations haute définition avec gestion des ratios (16:9, 1:1, 9:16) et personnalisation des styles visuels.
* **Analyse Documentaire :** Extraction, synthèse et interrogation interactive de fichiers (PDF, TXT, DOCX).
* **Synthèse Vocale (Text-to-Speech) :** Lecture audio intégrée des réponses avec animations visuelles et contrôle de lecture.
* **Panneau de Configuration & Diagnostics :** Personnalisation de l'interface, contrôle des paramètres audio, audit de santé du système et suivi des versions.

---

## 🛠️ Stack Technique

* **Framework :** Next.js / React
* **Styling :** Tailwind CSS (Design Dark Mode & Glassmorphism)
* **Architecture :** Composants modulaires orientés performance
* **Déploiement :** Vercel & GitHub Actions
